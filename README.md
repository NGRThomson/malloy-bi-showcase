# Malloy BI — showcase

A visual walkthrough of the project: spec-driven dashboards, the semantic layer, the gated agent,
per-chart revision history, and a read-only static demo of the app.

**Walkthrough:** https://ngrthomson.github.io/malloy-bi-showcase/
**Demo:** https://ngrthomson.github.io/malloy-bi-showcase/app/

The demo is the real app built statically. Filters and chart edits work in memory; persistence and
the assistant need the local app. Data is synthetic.
